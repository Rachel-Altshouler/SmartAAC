## מה זה?

ילדים רבים עם צרכים מיוחדים לא מדברים, או מדברים מעט. **SmartAAC** נותנת להם קול:
הילד/ה לוחץ/ת על סמלים (תמונות של מילים), בונה מהם משפט — והמכשיר **מקריא אותו בקול** בעברית.

ההורים והמורים מתאימים את הלוח לחיים של הילד/ה — האירועים שלו/ה, הנושא שלומדים השבוע,
תמונות של המשפחה ושל מה שעשו היום — וכל הצוות רואה ועובד על אותו לוח.

## איך מתחילים? (2 דקות)

1. **נכנסים לאתר** — סורקים את ה-QR או לוחצים על הקישור למעלה.
2. **רוצים רק לראות את לוח התקשורת?** לוחצים **"כניסת ילד/ה" ← "פתיחת לוח התקשורת"**.
   לוחצים על כמה סמלים (למשל "אני", "רוצה", "מים") ואז על **"הקרא"** — ושומעים את המשפט.
3. **הורה או מורה?** לוחצים **"כניסת הורה / מורה"**:
   - **בפעם הראשונה — "הרשמה":** אימייל, שם וסיסמה (או Google).
     יוצרים פרופיל לילד/ה, או מצטרפים לילד/ה קיים/ת עם הקוד שקיבלתם מההורה/המורה.
   - **מהפעם השנייה — "כניסה":** רק **קוד הילד/ה** (למשל `AAC-1234`) ו**הסיסמה**. המערכת מזהה אתכם ונכנסת ישר לילד/ה.

> 💡 קוד הילד/ה מגיע במייל אחרי ההרשמה, ומופיע תמיד בלוח הבקרה במסך "סקירה".

## מה יש במערכת?

### 🧒 אצל הילד/ה
| | |
|---|---|
| 🔣 **לוח סמלים** | שורות לפי נושאים (אוכל, אנשים, רגשות, פעולות…) וסמלי ליבה קבועים. כל לחיצה נכנסת למשפט, ו"הקרא" אומר אותו בקול |
| ✨ **עברית נכונה** | המשפט מוקרא בעברית תקינה, בלשון זכר או נקבה לפי הילד/ה |
| ⌨️ **מקלדת** | הקלדה אות-אות עם הצעות מילים, וכל מילה מקבלת תמונה |
| 📅 **אירועים** | לכל אירוע (טיול, יום הולדת…) סמלים שמתאימים לו |
| 📸 **מה עשיתי היום** | תמונות מבית הספר ומהבית — לוחצים על תמונה ומספרים מה עשו |
| 📖 **משחק סיפור** | סיפור קצר שבו הילד/ה בוחר/ת את המילה שממשיכה כל משפט |
| 💬 **שיחה** | שיחה קולית או כתובה עם עוזר עדין, שעונה בפשטות |

### 👩‍👧 אצל ההורה / המורה
| | |
|---|---|
| 📊 **סקירה** | מה קורה מחר, צוות הילד/ה והזמנת הורים ומורים במייל |
| 📅 **אירועים ולוח שנה** | כולל חגים ומועדים בישראל שנוספים לבד |
| 📚 **נושא שבועי** | הסמלים של הנושא מופיעים לילד/ה בראש הלוח |
| 🔣 **סמלים** | הוספה, מחיקה והסתרה של סמלים וקטגוריות, עם תמונות אמיתיות (ARASAAC) או תמונות משפחה |
| 📸 **מה עשינו היום** | המורה מעלה תמונות מבית הספר וההורה מהבית, עם משפט קצר לכל תמונה |
| 🖨️ **הדפסת סמלים** | כרטיסי סמלים להדפסה למשחקים (זיכרון, התאמה, בינגו) |
| 🌍 **ספרייה משותפת** | לוחות מוכנים שהורים ומורים אחרים שיתפו — הוספה בלחיצה |
| 📈 **התקדמות** | כמה משפטים, באילו נושאים, אילו סמלים — מכל המכשירים של הילד/ה יחד |
| 📱 **המסך של הילד/ה** | הופכים טאבלט למכשיר של הילד/ה: נפתח ישר ללוח, וההגדרות מוגנות בקוד של 4 ספרות |

## פרטיות

- כל ילד/ה פתוח/ה רק לצוות שלו/ה — מי שיצר/ה את הפרופיל ומי שהצטרף/ה עם הקוד.
- תמונות המשפחה ו"מה עשינו היום" נשמרות באחסון פרטי, ואינן משותפות בספרייה המשותפת.

## למפתחים

נבנה עם **Next.js 14** (App Router, TypeScript), **Tailwind CSS** ו-**Supabase** (אימות, Postgres, Row Level Security, Storage).
AI: **Gemini** ו-**Groq** (עם מעבר אוטומטי בין ספקים ותשובות מקומיות כשאין חיבור). מיילים: **Brevo**. סמלים: **ARASAAC**.

### הפעלה מקומית

```powershell
npm install
copy .env.example .env.local   # ומלאו את הערכים
npm run dev                    # http://localhost:3000
```

### משתני סביבה

| משתנה | שימוש | חובה? |
| --- | --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | Supabase — אימות ומסד נתונים | ✅ |
| `GEMINI_API_KEY`, `GEMINI_MODEL` | תיקון משפטים, סמלים לאירועים ול"מה עשינו היום", סיפורים | מומלץ |
| `GROQ_API_KEY`, `GROQ_MODEL` | שיחה ותמלול קול | מומלץ |
| `BREVO_API_KEY`, `BREVO_SENDER_EMAIL`, `BREVO_SENDER_NAME` | מיילי הזמנה וקוד הילד/ה | מומלץ |
| `OPENAI_API_KEY`, `OPENAI_MODEL` | ספק נוסף לשיחה והקראה | לא |
| `APP_BASE_URL` | כתובת האתר לקישורים במיילים (ברירת מחדל: הכתובת ב-Vercel) | לא |

### מסד נתונים

הסכימה ב-`supabase/schema.sql`, והשינויים ב-`supabase/migrations/` — מריצים לפי סדר המספור.
ב-Supabase ← Authentication ← URL Configuration: **Site URL** = כתובת האתר, ו-**Redirect URLs** כוללים את
`https://smart-aac.vercel.app/**` ואת `http://localhost:3000/**` (לכניסה עם Google ולאיפוס סיסמה).

### מבנה

```
app/          עמודים ו-API (auth, child-data, daily-story, shared-boards ...)
components/   המסכים — smartaac-demo.tsx (הלוח והדשבורד), daily-story, print-symbols, shared-library
lib/          AI, אימות, נתוני סמלים, Supabase
supabase/     schema.sql + migrations
docs/         ה-QR לאתר
```

### פריסה

כל `push` ל-`main` מתפרס אוטומטית ב-[Vercel](https://vercel.com/). את משתני הסביבה מגדירים גם ב-Vercel ← Settings ← Environment Variables.
